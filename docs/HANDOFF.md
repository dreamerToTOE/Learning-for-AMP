## 任务背景（已讨论清楚的事实）

- AMP 是使用对抗式运动风格奖励的强化学习方法；与普通 PPO、DeepMimic 的区别是训练中存在 Discriminator，但部署通常只保留 Actor。
- 原始 AMP 对混合运动风格可能存在模式坍塌/技能覆盖不足，但具体实验是否存在必须验证。
- “给专家数据打标签”不等于策略就会按标签执行。条件 Actor `a=pi(o,c)` 的 `c` 要由**训练环境指令**提供，部署时来自遥控器、用户命令或上层模块；不能使用只在仿真存在的隐藏标签。
- 条件判别器 `D(s_t,s_{t+1},c)` 评价“是否像指定技能”，而原始 D 评价“是否像混合专家分布”；这是设计选择，不是保证解决所有问题。
- 均衡采样=技能频率均衡；自适应采样=依据困难度动态调节。专家采样与 rollout 指令采样需要分别记录。
- 小样本技能的判别器输出不必然低；低技能覆盖还可能是奖励、任务条件、物理接触、数据质量问题。
- 所有结果必须通过独立评估/消融支持；条件 AMP / Multi-AMP 已有文献，不能宣称原创。
